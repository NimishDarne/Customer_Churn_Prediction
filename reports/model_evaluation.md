# Model Evaluation

## Baseline Logistic Regression

Accuracy: 80.21%
Precision: 65.29%
Recall: 54.31%
F1: 59.23%
ROC-AUC: 84.62%

## Balanced Logistic Regression

Accuracy: 74.85%
Precision: 51.69%
Recall: 80.13%
F1: 62.83%
ROC-AUC: 84.60%

## Observation

The balanced model has significantly higher recall and slightly
higher F1, while the baseline has higher precision and accuracy.

For customer churn, the balanced model is currently more useful
because detecting customers who are actually likely to churn is
important.
